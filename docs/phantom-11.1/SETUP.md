# Install and enable Phantom

1. Check the installed signing line. This APK updates compatible **reinstall-line 10.4/10.9 betas** in place. It cannot update the original **Jarvis 7.0** certificate. If Android reports a package conflict, stop; keep the installed app and data. Do not uninstall it to work around the mismatch. No original signing key was recovered and no key was generated for 11.1.
2. Download the ARM64 APK from the current release README. Android 10+ is required. Keep Play Protect enabled. Follow Android's install/update prompt only if it accepts this signer. Launch Jarvis; existing data and optional downloaded models remain.
3. Open **Settings → Phantom · floating HUD, wallpaper captions & request timings**. Tap **Open Android overlay permission**. In Android, select Jarvis and enable **Display over other apps**; return to Jarvis. Enable **floating HUD** separately. Permission denial leaves the assistant usable without floating windows.
4. Ask a short question, then open an ordinary app. The capsule appears below safe system insets; its separate task card shows the current real response. Tap the capsule to minimize/restore the card, **×** to dismiss until a new request, or **Expand ↗** to request the real selected Jarvis interface. For movement, enable **Edit position**, return to another app and drag the capsule. Resize, opacity, caption line count and auto-hide controls are in the Phantom screen. Disable Edit position when done.
5. For wallpaper captions, first use **Settings → Sentinel · wallpaper & sound → Preview / apply Jarvis wallpaper** and select it in Android's picker. Then enable **Allow live captions** in Phantom. Start listening yourself. Provisional speech is labeled; final text replaces it. Captions are never shown on the locked screen or during Android authentication. They expire eight seconds after the response ends. Neither selecting wallpaper nor granting overlay permission starts a microphone.
6. Open **Settings → Output voice · editable ID**. Select English or Spanish, privately enter your Fish Audio key, review the consent, run the actual fixed-sample preview, confirm it is the intended voice and enable it. English ID is editable; Spanish retains its exclusive ID. General questions may use Fish without private-data sharing. Memories, files, screens and other private replies require the separate private-text consent; otherwise read the text. Fish failure never substitutes another voice. Fish account charges and quota are independent of Jarvis.
7. For optional segment focus: in Phantom tap **Manage six consenting speaker profiles**. Download the verified optional speaker model, enroll only consenting people, and enable **Optional profile hint after wake commands**. Return to Phantom and enable experimental voice focus. Test in a quiet room first, then with TV/noise. If short commands or your voice are rejected, disable focus and use the Voice Lab. Do not use it as security authentication.
8. For direct lock, open **Settings → Open screen security** and grant the narrow Android device-admin lock permission if desired. “Lock my phone” then requests a direct supported lock. “Shut down” stops Jarvis and requests locking; it does not power off or erase the device. Unlock normally with Android.
9. To investigate delays, reproduce one short request, return to Phantom and tap **Refresh measured timings**. Record request number and stage times. Do not share voice API keys, raw private text or microphone samples. Timings are local observations, not cloud-generated promises. Stop cancels current work and removes overlays. A stalled operation returns an error with available text.

Keep a private off-cloud copy of the retained encrypted signing archive and its **separate** unlock file for future updates. Those files are outside this repository and must never be published or bundled in an APK. Existing workspace copies do not prove that an off-cloud backup exists.

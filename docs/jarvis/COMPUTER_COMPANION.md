# Computer companion

Existing companion/ is preserved. It has explicit two-sided QR pairing, private-LAN HTTPS/certificate pinning, signed command receipts, revocation and two narrowly scoped Chrome/search actions. General app/file/workspace/media/window/development commands are not implemented and require capability/consent contracts before expansion. No unrestricted shell endpoint added.

This session executed the existing 36 Python cases successfully using an isolated venv with the existing pinned requirements. Includes actual local TLS pairing/action/revocation and an actual controlled local Chromium page; browser sandbox disabling is limited to that existing isolated cloud fixture. It does not claim real Google search, Windows/macOS testing, native installers, Android microphone round trips or a public deployment. No companion code, stored keys or protocol changed.
